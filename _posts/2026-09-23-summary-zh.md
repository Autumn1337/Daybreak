### [TypeSafe AI 推出 Jev：只输出数值决策与概率的“决策模型”](https://simonwillison.net/2026/Sep/21/jev/) ⭐️ 8.0/10

TypeSafe AI 推出了名为 Jev 的新型“System One”（又称决策模型）模型形态。它能够接收非结构化文本输入，但不生成任何文本 Token，而是直接输出包含概率、分类和评分的浮点数。该 API 按每百万输入 Token 仅 0.042 美元计费且输出完全免费，并支持在上下文窗口内并行评估多个问题。 通过完全省去文本生成步骤，Jev 极大降低了推理延迟和成本，为垃圾过滤、数据打标和搜索重排序等高频分类与决策任务开辟了新技术路线。然而，由于它只返回数值而不提供文字解释，该模型变成了彻底的“黑盒”，使得模型评估与针对隐藏偏好的审计变得尤为重要。 Jev 的 API 支持三类问题：二分类（称为 Noul 问题，源自伯努利分布）输出 0 到 1 之间的概率、多选择题输出选项概率分布，以及指定区间的打分题。根据 Jev 1.13 的官方文档，该模型目前在处理精确数字、日期及对抗性内容方面仍存在局限。

rss · simonwillison.net · Sep 21, 23:09

### [扩散模型中双重下降与恶性过拟合机制的理论揭示](https://arxiv.org/abs/2609.26392v1) ⭐️ 8.0/10

研究人员结合随机特征模型的闭式学习曲线推导与 CelebA 数据集上的 U-Net 实验，解释了为何扩散模型的过参数化会导致灾难性的恶性死记硬背而非良性过拟合。研究发现，虽然每样本 $m$ 次噪声采样将插值峰值推迟至参数量 $p \sim nm$ 处，但测试损失在 $p \sim n$ 时就已开始上升。 该研究打破了现代深度学习中“过参数化天然带来良性过拟合”的传统假设，证明了未正则化的分数匹配会导致扩散模型对训练数据产生死记硬背。这表明大型生成模型若想获得最佳泛化性能，必须依赖适当的正则化手段（如早停法或脊惩罚）。 偏差-方差分解表明，分数估计器的偏差在 $p \sim n$ 处便开始增长，推动模型收敛于训练集的经验分数而非真实数据分布的分数。由于扩散模型训练通常使用大量噪声采样（$m \gg 1$），实际应用的大模型恰好处于插值峰值前的损失上升阶段，导致恶性过拟合损害泛化能力。

arxiv · Raphaël Urfin, Tony Bonnaire, Giulio Biroli · Sep 22, 13:30

**背景**: 在现代机器学习中，双重下降指的是测试误差随着模型参数增加先下降，在模型容量与数据规模匹配的插值阈值处出现峰值，随后在高度过参数化区域再次下降的现象。传统深度神经网络往往展现出“良性过拟合”，即超大模型即便完全拟合噪声数据也能保持良好泛化，但基于分数匹配的扩散模型在过参数化下的数学行为此前尚缺乏明确解析。

### [SAML 协议深度剖析：复杂 XML 带来的结构性安全缺陷](https://blog.trailofbits.com/2026/09/21/saml-a-fractal-of-bad-design/) ⭐️ 8.0/10

知名网络安全机构 Trail of Bits 发表了一篇深入的技术分析报告，指责 SAML（安全断言标记语言）协议存在结构性缺陷，指出其过度复杂的 XML 解析、规范化处理（C14N）、包覆式签名以及易受签名包裹攻击（XSW）等严重安全隐患。 鉴于 SAML 仍是企业级单点登录（SSO）的主流标准，深入理解这些结构性漏洞有助于安全团队与开发者防范身份验证绕过风险，并在评估转向 OpenID Connect（OIDC）等现代替代方案时做出更明智的决策。 该分析重点强调了 XML 的灵活性（特别是 XML 签名规范 XMLDSIG 中的包覆式签名与无 Schema 约束的规范化处理）如何引发巨大的攻击面，导致跨不同编程语言和函数库实现安全可靠的 SAML 验证变得极其困难。

hackernews · aray07 · Sep 22, 18:57

**背景**: SAML 是 2000 年代初期开发的一种基于 XML 的开放标准，用于在身份提供者（IdP）和服务提供者（SP）之间交换身份验证与授权数据。尽管它奠定了早期企业级单点登录（SSO）的基础，但其对 XML 签名和 XML 加密等复杂 XML 标准的过度依赖，导致其历史上频繁爆发各类实现漏洞与安全攻击。
